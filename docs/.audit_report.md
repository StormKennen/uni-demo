## 4. 关键工程化事实

- 请求层：统一 `src/services/http.ts`（Token/刷新/平台头），Apifox 生成层 `src/services/apifox/**`；禁止裸 `uni.request`。
- 主题：`src/utils/theme.ts` 双主题 token（`--theme-*`），全页面须走 token。
- 提交卡点：pre-commit 校验「改 `src/**` 必须同步 stage `docs/changelog.md`」（`scripts/check-changelog.cjs`）。
- 纯算法层：`src/engine/`（tomato-cipher、simple-scrambler），禁 uni API，vitest 覆盖（`pnpm test:tomato`）。
- 已有 Harness 体系：`HARNESS.md`（最高约束）、`AGENTS.md`、`CLAUDE.md`、`.cursorrules`/`.windsurfrules`、`.cursor/rules/01~03`。

## 5. 风险与注意点

1. `pages.json` 为路由唯一真理源：新增页面必须在对应分包节点注册，并同步 `src/config/tools.ts` 工具入口，需求文档（`docs/features/*.md`）中必须写明路由路径。
2. `vite.config.ts`、`src/manifest.json`、`.env.*`、部署脚本属禁改区（除非任务明确要求）。
3. TypeScript 4.9 + vue-tsc 1.x 组合较旧，全仓 `pnpm type-check` 存在历史配置/产物告警（`.vue.js` 残留、resolveJsonModule 配置），非单次任务应修复项。
