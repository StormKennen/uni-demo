# 前端专项审计简报（Frontend Audit & Discovery）

> 生成时间：2026-07-14 · 扫描对象：`package.json`、`src/manifest.json`、`src/pages.json`、`vite.config.ts` · 前端纯净视角（不含后端信息）

## 1. 框架与语言判定

| 维度     | 结论                                                                                                          |
| -------- | ------------------------------------------------------------------------------------------------------------- |
| Vue 版本 | **Vue 3**（`vue@^3.5.13`；`manifest.json` `"vueVersion": "3"`；`<script setup>` Composition API）             |
| 语言     | **TypeScript**（`typescript@^4.9.4` + `vue-tsc`；`env.d.ts`/`shime-uni.d.ts` 类型声明齐备）                   |
| 跨端框架 | uni-app 3（`3.0.0-4050720250324001`），编译目标以 **mp-weixin + H5** 为主                                     |
| 构建     | Vite 5.2.8 + `@dcloudio/vite-plugin-uni`；别名 `@`→src、`@img`→src/static/images；terser 压缩，生产去 console |

## 2. 全局插件 / 组件库 / 状态管理盘点

**UI 组件库**

- `@dcloudio/uni-ui`（easycom：`^uni-(.*)` 自动注册）
- 项目自研组件库：`src/components/`（PascalCase 如 `PageLayout`（easycom 注册）、`FolderPicker`、`ThemeRoot`，以及 `ga-*` 系列：ga-select/ga-calendar/ga-picker/ga-tags 等 40+ 组件）
- `lime-echart` / `l-echart`（图表）、`mp-html`（富文本渲染）

**全局插件与工具库**

- `pinia@^2.3.0` + `pinia-plugin-persistedstate`（状态持久化）
- `vue-i18n@^9.14.2`（国际化）
- `unplugin-auto-import`（vue / uni-app API 自动导入，生成 eslintrc-auto-import）
- 工具库：`lodash-es`、`dayjs`、`date-fns`、`crypto-js`、`qs`、`marked`（MD 渲染）、`uqrcodejs`（二维码）、`lunar-javascript`（黄历）、`mime`、`vconsole`（H5 调试）

**状态管理（Pinia，`src/stores/`）**

| Store            | 职责                                                                                                 |
| ---------------- | ---------------------------------------------------------------------------------------------------- |
| `useThemeStore`  | 白天/夜间主题 mode → `--theme-*` CSS 变量（`src/utils/theme.ts`），H5 侧 `#ifdef WEB` 同步 html 属性 |
| `useMallStore`   | 商城商品列表分页/推荐位                                                                              |
| `useGlobalStore` | 空壳占位（登录态实际在 `utils/autoLogin.ts`/`storage.ts`，属结构债 TD-7）                            |

**网络请求封装**

- 唯一合法出口 `src/services/http.ts`（Token/平台头自动携带、401 刷新重试、业务码校验）；Apifox 生成层 `src/services/apifox/**` 与手写 `*.api.ts` 均基于它。裸 `uni.request` 属技术债（TD-2，8 处存量）。

## 3. 路由与页面（pages.json）

- 共 **46 个路由**：主包 4 页（index/tools/mine/login，自绘 navbar + h5-tab-bar）+ 分包 `subPackages/{tools,user,common}` + `editor-core`。
- 全部使用 uni 路由 API 跳转，无 vue-router（合规）。
- 明细与功能简述见 `docs/features/000-existing-baseline.md` §1。
