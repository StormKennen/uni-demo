# 族谱 Canvas 树图需求规格

## 0. 元信息

| 项       | 内容                 |
| -------- | -------------------- |
| 功能名称 | 族谱 Canvas 血缘树图 |
| 所属域   | `subPackages/tools`  |
| 发布端   | H5 + mp-weixin       |
| 状态     | 开发中               |

## 1. 业务背景与页面

在既有家族族谱页面的“图谱 → 血缘树形”中展示梁姓谱系，避免微信小程序递归 Vue 组件仅渲染根节点的问题。沿用既有路由 `subPackages/tools/family-tree/index`，不新增页面路由。

## 2. 数据与绘制

- 数据由 `family-tree-chart.vue` 已构建的根节点树提供，本期不调用新接口。
- 在 Canvas 画布上绘制自上而下的父子连线、成员节点、姓名、世次和性别；各子女按所属支系横向分区，父节点对齐其子代分区中心；男性淡蓝、女性淡粉、未知使用中性色。
- 初始展示根节点与第一代子女，其他代默认折叠；点击有后代的节点展开/收起对应支系。
- 支持单指拖动画布、双指缩放（如平台事件可稳定获取），提供“适合屏幕/重置”操作；触摸节点打开现有成员选择/详情链路。
- H5 与微信小程序都使用当前 uni-app Canvas 组件适配，不使用 DOM、第三方图表依赖或递归 Vue 节点。
- 超宽支系允许缩放和拖动，窄屏初始按可视范围适配；姓名竖排便于子女较多的支系。

## 3. 页面状态与兼容

- Canvas 容器有明确可用高度；loading、空数据和绘制失败均有文本提示。
- 监听尺寸变化/首次布局后绘制；数据或展开状态变化后重绘。
- 画布尺寸和 DPR 使用 uni-app/小程序支持的方式获取；H5 不直接访问 `window`/`document`。
- Canvas 生命周期随视图卸载清理，避免页面往返后重复触摸监听。

## 4. 验收

- [ ] 初始可见根及子女，画布不止一个祖先节点。
- [ ] 父子连线自上而下，子代各自留在所属支系区域，节点性别颜色正确。
- [ ] 展开多条支系至少三代时互不混排，折叠后布局正确。
- [ ] 拖动和缩放不误触节点；点击节点选择正确。
- [ ] H5 与微信开发者工具均实测。
- [ ] `pnpm lint`、`pnpm type-check`、`pnpm build:h5`、`pnpm build:mp-weixin` 结果已记录。
