# 族谱从上到下树形图规格

## 0. 元信息

| 项       | 内容                       |
| -------- | -------------------------- |
| 功能名称 | 族谱原生血缘树图           |
| 所属域   | `subPackages/tools`        |
| 发布端   | H5 + mp-weixin             |
| 状态     | 已实现，待微信端实测       |

## 1. 业务背景与范围

在既有家族族谱页面的“图谱 → 血缘树形”中展示梁姓谱系，使用从上到下的父子层级。泳道和列表的组件、数据来源及记录内容均保持不变；本次只替换树图的布局与渲染层，主入口使用独立分包路由 `subPackages/record-tools/family-tree/index`；旧 `subPackages/tools/family-tree/*` 路由保留轻量跳转以兼容历史链接，不新增页面路由或接口。

## 2. 数据与布局

- 继续使用 `family-tree-chart.vue` 已构建的根节点树，不修改 `staticFamilyMembers`、成员 ID、父子关系或泳道/列表映射。
- 使用纯 TypeScript 布局函数计算节点坐标、舞台宽高和连接线；节点卡片及连接线使用扁平 `view` 列表，不用递归 Vue 节点或 Canvas。
- 节点宽度固定为160px，最小高度为160px；姓名逐字竖排，节点高度按姓名字符数动态增加，同代纵向间距以该代最高节点为准。卡片仅展示姓名和世次，不显示性别文字，不挤压操作区；底色仅对明确设置为女性的成员显示粉色，其余状态统一浅蓝色。展开支系只增加画布宽高，不缩放节点。
- 每个父节点水平居中于子女范围，自上而下连接父子；舞台高度取树内容高度与实测可用视口高度的较大值。少量节点在画布中垂直居中，多代展开只增大舞台，不缩小卡片。
- 树图按节点原始尺寸绘制，不做适屏缩放；横向滚动由树图内部的原生 `scroll-view scroll-x` 拖动，纵向滚动继续使用页面现有外层 `scroll-view scroll-y`；画布填满底部面板、顶栏扣除后的可用区域，并在面板/屏幕尺寸变化时重测；超宽/超高支系分别沿两个方向拖动查看。
- 首屏展开根节点并显示其子女，其他代默认折叠。卡片主体选择成员并打开详情；仅有子女的节点显示44×44的“+/−”圆形控件切换支系，不显示子女数量。展开/收起后保留当前视窗，并尽量让触发节点留在原屏幕位置，不跳回画布起点。
- 所有节点 key、选择和展开状态均使用成员 ID；同名成员仍作为不同记录显示，不以姓名合并。
- 布局只接受无环、每个成员最多一个父节点的树/森林。遇到循环或多父关系时显示解释，不重复卡片、不擅自选“主父”；泳道和列表仍可查看原记录。

## 3. 状态与双端兼容

- H5 与微信小程序共用相同的原生 `view` 节点和布局结果，不访问 `window`/`document`，不依赖第三方图表。
- 树图横向滚动区嵌套在页面纵向滚动区内，两者负责不同方向；泳道模式继续只使用当前纵向滚动容器。
- 空根树、非法关系有明确提示；切换/展开状态变化后重新计算平面布局。
- 测试覆盖父节点居中、固定节点尺寸、展开后舞台自然增大、循环与多父拓扑的保护。

## 4. 验收

- [ ] 首屏能看到祖先及子女，不是单独一个根节点。
- [ ] 多代展开后父子关系自上而下、支系不互相挤叠；卡片宽高保持不变。
- [ ] 树图可横向和纵向滚动；泳道和列表的显示与数据保持不变。
- [ ] 点卡片只选择/查看详情，点独立控制只展开/收起后代。
- [ ] 循环或多父关系不生成错误树图，提示用户到泳道/列表查看。
- [ ] H5 与微信开发者工具均实测。
- [ ] `pnpm lint`、`pnpm type-check`、`pnpm build:h5`、`pnpm build:mp-weixin` 结果已记录。
