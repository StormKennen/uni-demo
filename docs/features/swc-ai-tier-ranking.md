## 1. 业务上下文与页面流

评级榜用于展示当前数据库中已经映射到 SWC 图鉴的人物评级。第一方 `rta-ai` 是本项目自己的 RTA 综合评级；`swrt` 仅作为外部参考来源。页面不在前端计算分数，所有评级、报告日期和人物关联由后端已发布报告返回。

| 页面       | 路由                                                  | 跳转方式         | 来源入口         |
| ---------- | ----------------------------------------------------- | ---------------- | ---------------- |
| 魔灵强度榜 | `subPackages/tools/compendium/swc/tier-ranking/index` | `uni.navigateTo` | 魔灵召唤统一入口 |

需要新增的路由：

- `subPackages/tools/compendium/swc/tier-ranking/index`
- `navigationBarTitleText`: `魔灵强度榜`
- `navigationStyle`: `custom`
- 开启下拉刷新

需要新增的工具入口：

- `compendium-swc-tier-ranking`

## 2. 前后端 API 契约

复用已发布评级榜接口，页面直接调用 Apifox 生成方法：

| 功能     | 方法与路径                              | 鉴权   | 调用封装                           |
| -------- | --------------------------------------- | ------ | ---------------------------------- |
| 配置     | `GET /compendiums/tier-rankings/config` | public | `getCompendiumsTierRankingsConfig` |
| 最新榜单 | `GET /compendiums/tier-rankings/latest` | public | `getCompendiumsTierRankingsLatest` |

页面只接受 `status=published` 的后端结果。配置动态提供 `providers`、`regions`、`elements`、`tiers`、`stars` 和 `archetypes`，不得硬编码可用来源或区域；当前默认优先 `rta-ai`，不存在时回退后端返回的第一个 provider。

榜单请求参数：`compendiumId=swc`、`provider`、`region`、`elements`、`tiers`、`stars`、`archetypes`（均为逗号分隔多选）和 `locale=zh-CN`。属性、评级档位、星级和人物类型均支持多选；点击对应的“全部”会清空该组条件并省略参数。前端请求适配层会过滤空字符串和 `undefined`，不得向后端发送空筛选参数。报告返回后，关键词仍在本地执行。

## 3. 交互约束

- 首屏并行加载配置和最新榜单；配置失败或榜单失败展示可重试错误态。
- 来源/区域/属性改变时清空旧结果并只请求一次最新榜单。
- 评级档位和关键词搜索只过滤当前报告，不发起请求。
- 下拉刷新重新读取配置和当前榜单，失败时保留已有结果。
- 页面支持 `onShareAppMessage`、`onShareTimeline`；分享链接携带来源、区域、属性、档位、关键词、展示模式、品级数量、头像属性图标和评分显示状态，接收方打开后恢复相同视图。
- 点击人物进入统一人物详情页，并携带 `tab=stats`；没有 `character` 的条目保留展示但不跳转。

## 4. 页面信息层级

- 顶部：魔灵强度榜标题、评级口径、数据日期/赛季/版本。
- 筛选区默认收起，首行只展示区域及已选属性/评级摘要，可由图标展开；展开后区域以一行选择器展示，属性和评级保留多选。关键词输入暂时隐藏。显示行的数量、头像属性、展示模式和导出均使用同尺寸图标按钮；数量和头像右下角属性图标均默认关闭。切换列表/卡片聚合模式时按钮会短暂进入加载态并禁用，避免连续操作触发重复重排；导出按钮固定在该行最右侧。
- 显示行的评分按钮默认关闭，并同时控制两种榜单模式；卡片聚合模式开启后在人物头像左上角展示小号、带对比底色的评分角标，列表模式开启后在右侧评级徽标中展示分数，关闭后评级徽标收缩为紧凑的品级徽标，避免留下空白。
- 榜单区支持两种展示模式：卡片聚合模式按 SSS、SS、S、A、B、C、Other 连续分组，仅展示评级标签、可选属性角标、可选评分角标和头像网格；列表模式按评级分组展示单人物条目，展示名次、头像、星级、名称、人物类型图标与文案、编码和可选评分，评级组之间保留上下间距。
- 卡片聚合模式的评级分段连续衔接：中间分段无圆角，首段保留上方圆角，末段保留下方圆角；单行和多行分段统一只保留网格自身的上下内边距，不为单行增加最小高度。两种展示模式的五行信息都复用既有五行图标组件，列表正文不显示属性中文文案；开启属性图标后，头像右下角直接贴边展示透明背景的图标。导出复用 `useDeployedH5PosterExport`，通过已部署 H5 页面的专用海报渲染态，由 Painter 服务截取当前筛选后的全部分段长图。普通 H5 页面在首屏稳定且筛选状态持续一段时间后，会以延迟后台任务预热当前海报；用户导出时复用预热中的请求或已完成的缓存，不阻塞页面交互，筛选或显示状态变化会自动切换预热任务。海报只保留简化的筛选标题和评级内容，隐藏来源、日期、赛季、版本等说明行，不展示显示控制；URL 会携带区域、属性、评级、关键词、展示模式及三个显示开关，内容严格对应当前所见。因此部署最新 H5 是导出功能的前置条件。
- 空态：显示当前筛选无结果；错误态提供重新加载。
- 视觉上优先保证榜单卡片在移动端可截图，桌面 H5 使用更宽的网格；不做营销型 Hero，不遮挡榜单内容。

## 5. 主题与跨端

- 使用 `PageLayout`、`view`、`text`、`scroll-view`、`input`、`button` 和现有 SWC 头像/属性组件。
- 所有颜色走 `--theme-*` token；尺寸使用 `rpx`，不写死 `px`。
- H5 与 mp-weixin 共用页面逻辑；不使用 `window`、`document`、`localStorage`、`vue-router` 或裸 `uni.request`。
